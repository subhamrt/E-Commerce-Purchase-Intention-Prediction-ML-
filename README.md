E-Commerce Purchase Intention Prediction
📌 Project Overview

This project focuses on building a machine learning classification model to predict whether an online visitor will make a purchase based on their browsing behavior and session data. The model helps identify high-intent customers, enabling targeted marketing and improved conversion rates in e-commerce platforms.

🎯 Objective

Predict customer purchase intention (Buy / Not Buy)

Analyze online shopping behavior using web analytics data

Support data-driven decision-making for e-commerce businesses

📊 Dataset

Source: Online Shoppers Purchasing Intention Dataset

Records: 12,330 user sessions

Features: 18 behavioral and session-based attributes

Target Variable: Revenue (Binary: Purchase / No Purchase)

📈 Key Insights

PageValues was identified as a strong predictor of purchase behavior

Returning visitors showed higher purchase probability

Session duration and product page views significantly impacted conversion
